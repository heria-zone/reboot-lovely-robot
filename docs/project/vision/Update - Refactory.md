
Moving Forward
- LovelyRobot: Tribute
- LovelyRobot: Legacy
- LovelyRobot: Reboot

**Tribute** is a version where it would be the exact same as the original mod, only four robots (vanilla, honey, bunny, bunny2) and their only colours not the 16x but the exact same as the original mod. This is to honour lilacx02 for creating this amazing mod that has been my company for as long as I remember playing Minecraft.

**Legacy** this would be what the currently reboot version is, more robot types from the addon, and all robots types have 16x colours. This is to the players that like the current, mod, it is still vanilla friendly, but won't have any other robot types other than the original 4 and the 3 (dragon, neko, kitsune) addons.

**Reboot** this would be moving forward version, not the currently reboot, but the version 2.0 this would have the robot creator, with assembly, recall, terminal, path, frames, elements, new robots and so on.

**Conversion:**
You can convert the robots from the original mod 1.12.2 to either Tribute or Legacy. The Tribute and Legacy can convert between them. Legacy can convert to Reboot but reboot can't convert to either tribute nor Legacy.
